## 01. Go 시작하기 — 예제 안내

정리 문서: [Go 시작하기](../Go-시작하기.md)

### 실행 예제

**레포 루트에서** 실행합니다.

| 예제 | 확인하는 것 | 실행 |
|------|------------|------|
| [ex01-hello](ex01-hello/main.go) | 패키지 선언, `func main()`, `fmt.Println` | `go run ./01-hello-world/examples/ex01-hello` |

### 빌드해 보기

```bash
go build -o hello.exe ./01-hello-world/examples/ex01-hello
./hello.exe
```

`-o` 를 빼면 폴더 이름을 따라 `ex01-hello.exe` 가 만들어집니다.
빌드 산출물은 `.gitignore` 에서 제외되어 있습니다.
