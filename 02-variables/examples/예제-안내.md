## 02. 변수와 타입 — 예제 안내

정리 문서: [변수 선언과 사용](../변수-선언과-사용.md) · [변수의 타입](../변수의-타입.md)

### 실행 예제

**레포 루트에서** 실행합니다.

| 예제 | 확인하는 것 | 실행 |
|------|------------|------|
| [ex01-declaration](ex01-declaration/main.go) | 선언 6가지 방법, `:=` 재선언 규칙, 섀도잉 | `go run ./02-variables/examples/ex01-declaration` |
| [ex02-zero-value](ex02-zero-value/main.go) | 타입별 제로값, `nil` 슬라이스와 `nil` 맵의 차이 | `go run ./02-variables/examples/ex02-zero-value` |
| [ex03-type-inference](ex03-type-inference/main.go) | 리터럴이 어떤 타입으로 추론되는지 (`%T`) | `go run ./02-variables/examples/ex03-type-inference` |
| [ex04-conversion](ex04-conversion/main.go) | 명시적 변환, 절삭과 오버플로우, `strconv` | `go run ./02-variables/examples/ex04-conversion` |
| [ex05-string-rune](ex05-string-rune/main.go) | `len()`은 바이트 수, `range`는 rune 단위 | `go run ./02-variables/examples/ex05-string-rune` |

### 에러 예제

`_errors/` 안의 파일은 **일부러 컴파일에 실패하도록** 만든 예제입니다. 실행이 아니라 **에러 메시지를 읽는 것**이 목적입니다.

| 예제 | 확인하는 에러 |
|------|--------------|
| [err01-unused-variable](_errors/err01-unused-variable/main.go) | `declared and not used` — 대입만 하는 것도 미사용임 |
| [err02-unused-import](_errors/err02-unused-import/main.go) | `imported and not used` |
| [err03-implicit-conversion](_errors/err03-implicit-conversion/main.go) | `mismatched types` — 암묵적 변환이 없음 |
| [err04-constant-overflow](_errors/err04-constant-overflow/main.go) | 상수는 손실 변환 자체가 막힘 (변수는 통과) |

파일 경로를 직접 지정해 실행합니다.

```bash
go run ./02-variables/examples/_errors/err01-unused-variable/main.go
```

```
declared and not used: a
declared and not used: msg
declared and not used: assigned
```

> 폴더 이름이 `_` 로 시작하면 Go 도구가 무시합니다. 덕분에 이 파일들이 있어도 `go build ./...` 와 `go vet ./...` 는 정상 통과하고, 에디터도 빨간 줄을 띄우지 않습니다.
