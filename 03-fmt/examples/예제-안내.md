## 03. fmt 패키지를 이용한 텍스트 입출력 — 예제 안내

정리 문서: [fmt 패키지를 이용한 텍스트 입출력](../fmt-패키지를-이용한-텍스트-입출력.md)

### 실행 예제

**레포 루트에서** 실행합니다.

| 예제 | 확인하는 것 | 실행 |
|------|------------|------|
| [ex01-print](ex01-print/main.go) | `Print`·`Println`·`Printf` 의 공백·개행 규칙, 반환값, `Sprintf`·`Fprintln` | `go run ./03-fmt/examples/ex01-print` |
| [ex02-verbs](ex02-verbs/main.go) | `%v` `%+v` `%#v` `%T` 등 서식 문자, 서식 불일치 시 `%!d(...)` 표시 | `go run ./03-fmt/examples/ex02-verbs` |
| [ex03-width-precision](ex03-width-precision/main.go) | 너비, `0`·`-`·`+` 플래그, `%f`·`%g`·`%s` 의 정밀도, 짝수 반올림 | `go run ./03-fmt/examples/ex03-width-precision` |
| [ex04-scan-rules](ex04-scan-rules/main.go) | `Scan`·`Scanln`·`Scanf` 가 입력을 나누는 방식, `&` 를 빼먹었을 때 | `go run ./03-fmt/examples/ex04-scan-rules` |
| [ex05-stdin-leftover](ex05-stdin-leftover/main.go) | 잘못된 입력이 스트림에 남아 다음 입력을 망가뜨림 | `go run ./03-fmt/examples/ex05-stdin-leftover` |
| [ex06-read-line](ex06-read-line/main.go) | 한 줄을 통째로 읽고 파싱해서 찌꺼기를 남기지 않음 | `go run ./03-fmt/examples/ex06-read-line` |

`ex04-scan-rules` 는 키보드 입력 대신 문자열에서 읽는 `Sscan` 계열을 썼습니다. 규칙은 `Scan` 계열과 같고, 입력 없이 실행만 하면 결과가 재현됩니다.

`ex03-width-precision` 의 출력 일부입니다. `[ ]` 안이 실제로 찍힌 칸입니다.

```
[  123] [  456]      ← %5d
[00123] [00456]      ← %05d  오른쪽 정렬 그대로, 채우는 문자만 0
[123  ] [456  ]      ← %-5d, %-05d  - 와 0 을 같이 쓰면 0 은 무시
[  324.13]           ← %8.5g  정밀도 = 유효숫자 5개
[03.2e+02]           ← %08.2g 유효숫자 2개로는 324 를 못 나타내 지수 표기
[2] [4]              ← %.0f 에 2.5, 3.5  짝수 쪽으로 반올림
```

### 입력 예제 실행하기

`ex05`, `ex06` 은 키보드 입력을 기다립니다. **같은 입력**을 넣고 결과를 비교해 보세요.

```
3 a b
5 6
```

`ex05-stdin-leftover` — 첫 줄의 실패가 뒤까지 번집니다.

```
1번째 입력 (정수 2개): 3 a b
  -> 에러: expected integer | 읽은 개수: 1
2번째 입력 (정수 2개):   -> 에러: expected integer | 읽은 개수: 0
3번째 입력 (정수 2개):   -> 에러: unexpected newline | 읽은 개수: 0
4번째 입력 (정수 2개): 5 6
  -> 성공: 5 6
```

2번째와 3번째는 **입력을 기다리지도 않고** 바로 에러가 납니다. 스트림에 남아 있던 `b` 와 개행을 읽었기 때문입니다.

`ex06-read-line` — 실패한 줄만 버려지고 다음 줄은 정상입니다.

```
1번째 입력 (정수 2개): 3 a b
  -> 에러: expected integer | 읽은 개수: 1 | 버려진 줄: "3 a b"
2번째 입력 (정수 2개): 5 6
  -> 성공: 5 6
```

매번 타이핑하기 번거로우면 파이프로 넣을 수 있습니다. (bash 기준)

```bash
printf '3 a b\n5 6\n' | go run ./03-fmt/examples/ex05-stdin-leftover
printf '3 a b\n5 6\n' | go run ./03-fmt/examples/ex06-read-line
```

> 파이프로 넣으면 입력한 글자가 화면에 찍히지 않아서 프롬프트와 결과가 한 줄에 붙어 보입니다.

### 에러 예제

`_errors/` 안의 파일은 **일부러 실패하도록** 만든 예제입니다. 이번 챕터의 예제는 컴파일 에러가 아니라 **`go vet` 에러**입니다.

| 예제 | 확인하는 에러 |
|------|--------------|
| [err01-printf-mismatch](_errors/err01-printf-mismatch/main.go) | 서식과 인자의 타입·개수 불일치, `Println` 에 서식 문자를 넣은 실수 |

`go run` 은 그대로 실행되고, 출력에 표시만 남습니다.

```bash
go run ./03-fmt/examples/_errors/err01-printf-mismatch/main.go
```

```
이름: %!d(string=gopher)
이름: gopher, 나이: %!s(MISSING)
나이: %d 10
```

`go vet` 은 실행 전에 잡아냅니다.

```bash
go vet ./03-fmt/examples/_errors/err01-printf-mismatch/main.go
```

```
main.go:18:22: fmt.Printf format %d has arg name of wrong type string
main.go:19:34: fmt.Printf format %s reads arg #2, but call has 1 arg
main.go:20:2: fmt.Println call has possible Printf formatting directive %d
```

> 이 파일을 일반 예제 폴더에 두면 `go build ./...` 는 통과하지만 `go vet ./...` 가 실패합니다. 그래서 Go 도구가 무시하는 `_errors/` 에 두었습니다.
