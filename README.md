## 폴더 구조 규칙

새 주제는 **폴더 하나 추가**로 끝납니다.

```
NN-주제이름/
├── 주제이름.md            ← 정리 본문 (주제가 넓으면 여러 문서로 나눈다)
└── examples/             ← 실행 가능한 예제
    ├── 예제-안내.md        ← 예제 목록·실행 방법
    ├── exNN-이름/main.go
    └── _errors/          ← 일부러 컴파일에 실패시켜 에러 메시지를 확인하는 예제
        └── errNN-이름/main.go
```

- **번호는 재사용하지도, 다시 매기지도 않는다.** 중간에 배운 주제가 생겨도 맨 뒤에 새 번호로 붙이고, 읽는 순서는 위 목차에서만 조정한다. 그래야 폴더 경로와 링크가 영원히 안 깨진다.
- **`README.md`라는 이름은 레포 루트에만 쓴다.** 파일 이름만 보고 무슨 문서인지 알 수 있어야 한다.
- **주제가 넓으면 문서를 나눈다.** 폴더 안에 목차 문서를 따로 만들지 말고 **루트 목차에 하위 표로 나열하고**, 문서끼리는 각 문서 끝의 `### 관련 문서`로 연결한다.
- **파일명에 공백을 쓰지 않는다.** 마크다운 링크가 `%20`으로 지저분해진다.
- 예제 폴더 이름은 **정리 문서의 섹션 순서와 맞춘다.** (`ex04-conversion` ↔ "타입 변환")

### Go 때문에 자바 레포와 다른 부분

- **주제 폴더 이름은 영문으로 쓴다.** Go는 import 경로에 한글을 허용하지 않아서, `.go` 파일이 들어가는 폴더가 한글이면 `go build ./...` 와 에디터 지원이 통째로 깨진다.

  ```
  malformed import path "hello/02-변수와-타입/examples": invalid char '변'
  ```

  대신 **문서(`.md`) 파일 이름은 한글을 그대로 쓴다.** import 경로와 무관하다.
- **예제는 파일 하나가 아니라 폴더 하나다.** 한 폴더 = 한 패키지라서, 같은 폴더에 `func main()`이 여러 개면 충돌한다. 그래서 예제마다 폴더를 따로 둔다.
- **에러 예제 폴더는 `errors/`가 아니라 `_errors/`다.** `_`로 시작하는 폴더는 Go 도구가 통째로 무시하므로, 컴파일에 실패하는 파일을 넣어둬도 `go build ./...`가 깨지지 않는다.

## 예제 실행

**레포 루트에서** 실행하세요.

```bash
# 정상 예제 - 폴더를 지정해 실행
go run ./02-variables/examples/ex01-declaration

# 에러 예제 - 파일을 지정해 실행하고, 출력되는 에러 메시지를 읽는다
go run ./02-variables/examples/_errors/err01-unused-variable/main.go
```

전체 검사는 루트에서 한 번에 합니다. `_errors/`는 자동으로 제외됩니다.

```bash
go build ./...   # 전부 컴파일되는지
go vet ./...     # 의심스러운 코드가 없는지
go fmt ./...     # 표준 포맷으로 정렬
```

> Windows 터미널에서 한글이 깨지면 `chcp 65001` 을 먼저 실행하세요.
